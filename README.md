NFT Marketplace

NFT Marketplace is a React web app for browsing digital collectibles, NFT items, sellers, author profiles, and item details. I built this project to practice creating a polished front-end marketplace with React, API data, routing, loading states, sliders, filters, and animations.

What The App Does
This app lets users explore NFT-style marketplace content. Users can view hot collections, new items, top sellers, browse by category, open individual NFT details, and view author profile pages.

Main Features

Landing Page -
The home page has a marketplace-style hero section with a call-to-action button that sends users to the explore page.

Hot Collections -
The app shows a carousel of hot NFT collections. Each collection links to an item details page and includes creator information.

New Items -
The new items section displays NFT cards with images, prices, likes, creator profiles, and countdown timers.

Top Sellers -
The top sellers section shows a list of marketplace authors with profile images, verified icons, and ETH values.

Explore Page -
The explore page shows more NFT items in a grid. Users can sort items by price or likes and load more items.

Item Details -
Each NFT has a details page that shows the item image, title, views, likes, description, owner, creator, and price.

Author Profiles -
Author pages show profile information, follower count, wallet text, a follow button, and NFTs connected to that author.

Loading States -
The app uses skeleton loading components while API data is being fetched. This helped me practice making the UI feel smoother while data is loading.
